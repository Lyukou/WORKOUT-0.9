如何安装到 Pixel 桌面

前提：页面必须通过 HTTPS 链接打开（本地 file:// 文件不行）。

  1. 把这 3 个文件（index.html、manifest.json、sw.js）上传到任意 HTTPS 托管。
  2. 用 Pixel 的 Chrome 打开得到的 HTTPS 链接。
  3. 点右上角 ⋮ → 安装应用（或地址栏右侧出现的小手机图标，直接点）。
  4. 如果菜单里只有“添加到主屏幕”，也可以，效果是快捷方式。

推荐托管（免费）：

  • GitHub Pages：新建仓库 → 上传 3 个文件 → Settings → Pages → 分支选 main → 保存，几分钟后得到 https://用户名.github.io/仓库名/
  • Netlify：注册后把整个文件夹拖进 app.netlify.com/drop，立刻得到 HTTPS 链接。

安装后桌面会出现绿色杠铃图标，点开全屏运行，数据存在手机本地，不联网也能练。
